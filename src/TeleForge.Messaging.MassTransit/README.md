# TeleForge.Messaging.MassTransit

MassTransit queue backend for TeleForge, for outbox-style delivery of outbound Telegram messages over RabbitMQ.

Part of [TeleForge](https://github.com/deniscuciuc/teleforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/teleforge#readme) for usage.

```
dotnet add package TeleForge.Messaging.MassTransit
```
