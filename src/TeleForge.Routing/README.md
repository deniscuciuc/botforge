# TeleForge.Routing

Attribute-driven update routing for TeleForge — commands, callback queries, text, media and every other update type — with a middleware pipeline for authorization, conversation state, rate limiting and localization.

Part of [TeleForge](https://github.com/deniscuciuc/teleforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/teleforge#readme) for usage.

```
dotnet add package TeleForge.Routing
```
