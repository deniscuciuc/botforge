# BotForge.Core

Core abstractions for BotForge: the update context, middleware contract, bot client provider and send result. Every other BotForge package builds on this one.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Core
```
