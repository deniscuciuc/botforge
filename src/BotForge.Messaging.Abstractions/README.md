# BotForge.Messaging.Abstractions

Outbound messaging contracts for BotForge: the message service, queue backend and send middleware.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Messaging.Abstractions
```
