# TeleForge.Contracts

Message contracts shared between a TeleForge ingress process and a sender process when the two are deployed separately.

Part of [TeleForge](https://github.com/deniscuciuc/teleforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/teleforge#readme) for usage.

```
dotnet add package TeleForge.Contracts
```
