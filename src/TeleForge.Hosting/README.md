# TeleForge.Hosting

Host wiring for TeleForge. AddTelegramMonolithHost composes ingress, routing and sending in one call; separate ingress and sender hosts are available for a split deployment.

Part of [TeleForge](https://github.com/deniscuciuc/teleforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/teleforge#readme) for usage.

```
dotnet add package TeleForge.Hosting
```
