# TeleForge.RateLimiting.Redis

Redis-backed per-user rate limiting for TeleForge, so limits hold across every instance rather than per process.

Part of [TeleForge](https://github.com/deniscuciuc/teleforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/teleforge#readme) for usage.

```
dotnet add package TeleForge.RateLimiting.Redis
```
