# BotForge.Messaging.MassTransit

MassTransit queue backend for BotForge, for outbox-style delivery of outbound Telegram messages over RabbitMQ.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Messaging.MassTransit
```
