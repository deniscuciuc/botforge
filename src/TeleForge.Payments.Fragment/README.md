# TeleForge.Payments.Fragment

Fragment payouts for TeleForge — an API client, auth manager, payout provider, health check and metrics.

Part of [TeleForge](https://github.com/deniscuciuc/teleforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/teleforge#readme) for usage.

```
dotnet add package TeleForge.Payments.Fragment
```
