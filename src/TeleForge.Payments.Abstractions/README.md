# TeleForge.Payments.Abstractions

Payment contracts for TeleForge: invoices, typed payloads, pre-checkout and refund contexts, anti-fraud checks and payout providers.

Part of [TeleForge](https://github.com/deniscuciuc/teleforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/teleforge#readme) for usage.

```
dotnet add package TeleForge.Payments.Abstractions
```
