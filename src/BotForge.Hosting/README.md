# BotForge.Hosting

Host wiring for BotForge. AddTelegramMonolithHost composes ingress, routing and sending in one call; separate ingress and sender hosts are available for a split deployment.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Hosting
```
