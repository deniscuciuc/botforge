# BotForge.Contracts

Message contracts shared between a BotForge ingress process and a sender process when the two are deployed separately.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Contracts
```
