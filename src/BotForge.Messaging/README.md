# BotForge.Messaging

Outbound messaging for BotForge — a fluent message and keyboard builder, an in-memory queue, and a send pipeline with rate limiting, retries, a circuit breaker and metrics.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Messaging
```
