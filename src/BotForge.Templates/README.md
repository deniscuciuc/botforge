# BotForge.Templates

YAML message templates for BotForge with conditionals, loops, partials, formatters, an emoji registry and keyboard definitions — so message copy changes without a redeploy.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Templates
```
