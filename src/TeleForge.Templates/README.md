# TeleForge.Templates

YAML message templates for TeleForge with conditionals, loops, partials, formatters, an emoji registry and keyboard definitions — so message copy changes without a redeploy.

Part of [TeleForge](https://github.com/deniscuciuc/teleforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/teleforge#readme) for usage.

```
dotnet add package TeleForge.Templates
```
