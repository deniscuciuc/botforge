# BotForge.Routing

Attribute-driven update routing for BotForge — commands, callback queries, text, media and every other update type — with a middleware pipeline for authorization, conversation state, rate limiting and localization.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Routing
```
