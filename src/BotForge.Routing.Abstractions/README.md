# BotForge.Routing.Abstractions

Routing contracts for BotForge: handler interfaces, routing attributes and the authorization model. Reference this from a project that defines handlers without hosting them.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Routing.Abstractions
```
