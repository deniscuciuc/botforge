# BotForge.Payments.Abstractions

Payment contracts for BotForge: invoices, typed payloads, pre-checkout and refund contexts, anti-fraud checks and payout providers.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Payments.Abstractions
```
