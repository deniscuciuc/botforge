# BotForge.Payments.Fragment

Fragment payouts for BotForge — an API client, auth manager, payout provider, health check and metrics.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.Payments.Fragment
```
