# BotForge.RateLimiting.Redis

Redis-backed per-user rate limiting for BotForge, so limits hold across every instance rather than per process.

Part of [BotForge](https://github.com/deniscuciuc/botforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/botforge#readme) for usage.

```
dotnet add package BotForge.RateLimiting.Redis
```
