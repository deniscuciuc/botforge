# TeleForge.Payments

Payments for TeleForge — invoices, pre-checkout validation, payment processing, refunds, subscriptions, Telegram Stars, gifts, paid media, an anti-fraud pipeline and payouts.

Part of [TeleForge](https://github.com/deniscuciuc/teleforge), a Telegram bot framework for .NET. See the [documentation](https://github.com/deniscuciuc/teleforge#readme) for usage.

```
dotnet add package TeleForge.Payments
```
