# BotForge.Templates.DotNet

`dotnet new` templates for [BotForge](https://github.com/deniscuciuc/botforge).

```
dotnet new install BotForge.Templates.DotNet
dotnet new botforge-bot -n MyBot
dotnet new botforge-handler -n WelcomeHandler
```
