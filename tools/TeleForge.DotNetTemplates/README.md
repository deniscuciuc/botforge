# TeleForge.Templates.DotNet

`dotnet new` templates for [TeleForge](https://github.com/deniscuciuc/teleforge).

```
dotnet new install TeleForge.Templates.DotNet
dotnet new teleforge-bot -n MyBot
dotnet new teleforge-handler -n WelcomeHandler
```
