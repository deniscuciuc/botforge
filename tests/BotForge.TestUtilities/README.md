# BotForge.TestUtilities

Test doubles for [BotForge](https://github.com/deniscuciuc/botforge): a fake Telegram bot
client that records what was sent, an update factory for building realistic `Update`
objects, and a listener that captures emitted metrics.

It has no dependency on any assertion or test framework — use it with xUnit, NUnit, MSTest
or anything else.

```
dotnet add package BotForge.TestUtilities
```
